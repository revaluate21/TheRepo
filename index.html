    Sensor troubleshooting

    This hosted version runs on HTTPS, which is required for geolocation. On Pixel/Chrome, allow Location when prompted. For compass, also make sure Android Settings → Apps → Chrome → Permissions → Nearby devices / motion-related access (where offered) and Chrome Site settings do not block sensors. If compass remains unavailable, the arrow still works north-up using GPS bearing.
